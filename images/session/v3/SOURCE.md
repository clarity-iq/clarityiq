# Session visuals v3: painted art (style C)

All images in this folder were generated for ClarityIQ with the agent's image tool
(Nov 25, 2026) in one style: warm cream field, realistic soft-painted look, muted
sage and terracotta. No text is painted into any image; every label, ray and dot is
drawn in code (HTML/SVG) so it can be edited and translated.

| File | Screen | Notes |
|---|---|---|

| `focal.jpg` | 2 Basics, focal points | v4 repaint with real depth: book and reading glasses large in the near foreground, laptop at arm's length on the desk, countryside through the window far away. Near / Arm's length / Far labels drawn in code. |
| `astigmatism-eye.jpg` | 2 Basics, astigmatism | Astigmatism option B base painting (no rays). The two-focus rays (one focal point in front of the retina, one behind) are an SVG overlay in `VISUALS_MANIFEST.slides.astigmatism.overlay`. |
