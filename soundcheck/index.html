Sound check

This page checks your phone's speaker and microphone, one step at a time. It takes about 6 minutes. Nothing is saved or sent anywhere.

Turn your volume up. After each test, tap Heard or Didn't hear. At the end, read the short code at the bottom back to us.

1. Speaker

Each button plays three short beeps a different way. The mic stays off.

2. Microphone

Tap a button, allow the mic if asked, and talk for a few seconds. Watch the green bar.

3. Speaker and mic together

This is what a voice session does. Each button turns the mic on, then plays beeps. Tell us if you hear them.

4. Mic, measured other ways

Each button turns the mic on and measures it a different way. Keep talking the whole time the button is busy. 4A plays your own voice back to you, like the WebRTC test page.

Your result code

Read this code back to us, or tap Copy results and paste it in a message.
